Performance & system architecture

Engineered in Rust to keep memory flat and retrieval offline

Instead of serializing entire PDFs over IPC or sending private manuscripts to external embedding servers, Foliet streams byte ranges on demand and runs quantized ONNX vector search in-process.

Peak RAM on 500-page PDF 68 MB -89% vs 640 MB base64 IPC copy
Local ONNX query latency 14 ms 30x faster vs 420 ms cloud round-trip
Default ONNX retrieval score 0.853 MedEmbed-small-v0.1 (384 dimensions)
API key encryption at rest 256-bit AES-256-GCM + fresh 12-byte nonce

1. HTTP 206 byte-range streaming & ISO 32000-1 burn loop

Local PDFs stream through an 8-slot Rust file pool without base64 serialization. Pressing Ctrl S writes Form XObject appearances directly into the PDF via lopdf.

2. Offline ONNX vector indexing & AES-256-GCM key vault

Page lines and bounding rects are tokenized and embedded in Rust via ort into rag.db, while provider API keys are encrypted with a 256-bit OS Keyring master key.

Capabilities

Built around the actual workflow of reading and synthesizing papers

ISO 32000-1 annotation burning & customizable presets

Annotate with Highlight, Underline (solid, squiggle, dashed), Strikethrough, debounced Sticky Notes, freehand vector ink (perfect-freehand), click-and-drag Eraser, and high-DPI Figure Crops. When you press Ctrl S, Rust's lopdf burns your markups as standard Form XObject streams while keeping full revision-tracked Undo and Redo history.

lopdf 0.47 Form XObjects zundo temporal store Tool customizer modal

Encrypted API key vault

Provider keys never touch localStorage, settings.json, or SQLite. They are encrypted in secrets.enc via AES-256-GCM with the master key in your OS Credential Manager.

aes-gcm OS Keyring
