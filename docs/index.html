Security & Local-First Architecture

Your papers stay on disk. Your API keys stay encrypted.

Foliet never uploads your library to a proprietary backend and never stores provider API keys in plaintext localStorage, JSON, or SQLite.

AES-256-GCM Secrets Vault (secrets.enc)

Every API key write generates a fresh cryptographically random 12-byte nonce in Rust via aes-gcm + OsRng, rejecting tampered ciphertexts or mismatched keys.

OS Credential Manager Master Key

The 256-bit master key is stored lazily in Windows Credential Manager, macOS Keychain, or Linux Secret Service via keyring — never bundled in frontend storage.

In-Memory Frontend Hydration

Keys exist strictly in JS memory during runtime, are masked in password inputs, are never logged in Rust or TypeScript, and legacy plaintext entries are automatically migrated and scrubbed on startup.
